# REAL OTD PWA v2

New features:
- Edit card rarity and multiplier
- Add new cards
- Archive and restore sold cards
- Recalculates all daily claims and overlap automatically
- Backup and restore collection/progress
- No streak tracking

To update your Netlify site:
1. Extract this ZIP.
2. In Netlify, open your existing site.
3. Go to Deploys and drag the extracted `real_otd_pwa_v2` folder into the deploy area.
4. Reopen the app and refresh once.

Automatic Real username syncing is not included because it requires an official Real API or partnership.
